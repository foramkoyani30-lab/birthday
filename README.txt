SWAYAM — MOON & STARS BIRTHDAY WEBSITE

1. Extract the ZIP.
2. Open index.html in Chrome.
3. This is a single-page, chapter-style interactive birthday surprise.

SECTIONS: Welcome, Cute Memories, Pop the Wishes, Birthday Puzzle, One Last Surprise, A Letter Just For You.

ADD PHOTOS: Put 3 images inside the photos folder and name them photo1.jpg, photo2.jpg, photo3.jpg.

EDIT WORDING: Open index.html in VS Code or Notepad and change the text. The website uses HTML, CSS and JavaScript.
